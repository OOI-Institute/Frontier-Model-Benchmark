# Security and Benchmark Integrity

Please report security-sensitive or benchmark-integrity issues privately to the repository maintainers before public disclosure when practical.

Relevant issues include:

- arbitrary code execution in benchmark infrastructure,
- sandbox escape,
- credential or secret exposure,
- hidden-answer or grader leakage,
- benchmark canary leakage,
- reward-hacking paths that invalidate reported success,
- unauthorized network/filesystem access,
- reproducibility failures that materially alter scores.

Do not include real credentials, private model data, or sealed evaluation content in public issues.

Non-sensitive bugs, task ambiguity, scoring errors, and documentation defects may be filed publicly.
